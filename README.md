# Закрытый CRM-бот для Telegram (роли: админ / наставник / агент)

## Возможности
- **Закрытый доступ**: новый пользователь при /start подаёт заявку, наставник вручную одобряет или отклоняет (кнопки приходят всем наставникам).
- **Меню** (как у конкурента): 👨 Профиль · 🗣 Чат агентов · 📝 Запись на собеседование · 🎓 Обучение · 💳 Реквизиты · 👥 Мои модели.
- **Профиль**: роль, ID, реквизиты, баланс, Stars.
- **Мои модели**: добавление, фильтр по статусам (Активные ✅ / Не активные ⚠️ / Слив 🚫), смена статуса кнопками.
- **Панель наставника**: заявки на вступление, заявки на собеседование, добавление уроков, ссылка на чат агентов, начисление баланса.
- **Админ**: `/mentor tg_id` — выдать роль наставника, `/demote tg_id` — снять.

## Установка
```bash
pip install -r requirements.txt
```

## Настройка
1. Создайте бота у @BotFather, получите токен.
2. Узнайте свой Telegram ID через @userinfobot.
3. Впишите их в `config.py` (или задайте переменные окружения `BOT_TOKEN` и `ADMIN_ID`).

## Запуск
```bash
python main.py
```
Первым нажмите /start сами — вы автоматически станете админом. Дальше назначайте наставников командой `/mentor tg_id` (человек должен сначала нажать /start).

## База данных
SQLite-файл `crm.db` создаётся автоматически. Основная сущность кандидата/модели хранится в `models`; статусы собеседования и работы идут по этой же записи. Основные таблицы: users, models, materials, teams, partners, processed_shifts, sheet_history, settings.
